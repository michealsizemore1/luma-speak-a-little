Instruction manualEverything you need to use Luma and Ask Kumo
Getting started and navigation

Use the published website for microphone access, Ask Kumo, and updates. Select the ☰ menu to move between sections. My Personal Plan is your only scheduled plan; Lessons and practice tools support it.

My Personal Plan

Choose a start date, open the current Plan Day, complete the activities in order, check them off, and select Complete Plan Day. Each day is limited to about 15 minutes. Missed assignments remain available.

Lessons and Practice Lab

Lessons is a reference library and does not independently award progress. Practice Lab contains pronunciation, memory review, scenarios, listening, and the Mistake Notebook. For pronunciation, select the microphone, speak clearly, and wait for feedback.

How to use Ask Kumo

Select Ask Kumo in the lower-right corner, type in English or Spanish, and select the arrow. Try: “Practice an A1 café conversation with me. Ask one question at a time and explain corrections in English.” Kumo can correct sentences, explain grammar, quiz vocabulary, and role-play real situations.

If it does not respond, confirm you are online, use the published site, refresh, and try “Hola.” Never share passwords, payment details, or API keys.

Progress, backup, and restore

Progress changes only after a Plan Day is completed. Use Download backup to save your progress and Restore backup to load a saved file.

Using Luma on a phone

Open the published site in Chrome or Safari. Use Add to Home screen on Android or Safari’s Share → Add to Home Screen on iPhone. No app-store download is required.
